# Hardpoint

Low-poly mech combat in the browser, inspired by the 90s mech sims. Built with Three.js, TypeScript and Vite.

```bash
npm install
npm run dev      # http://localhost:5173/
npm run verify   # typecheck, lint, unit tests, build, headless smoke test
```

Debug URL params: `?scene=desert&seed=1&cam=orbit|free&t=3` (`t` freezes the sim at that time). Press F1 to toggle the free-fly camera.
